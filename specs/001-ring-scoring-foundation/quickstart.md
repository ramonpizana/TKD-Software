# Quickstart - Ring Scoring Foundation

## Prerrequisitos

- Node.js 22 o superior
- npm 11 o superior

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Validar el repositorio

```bash
npm run validate
```

## Smoke test manual

1. Abrir la app local.
2. Seleccionar un atleta distinto en la cola.
3. Enfocar un juez y usar flechas o botones para aplicar deducciones.
4. Confirmar que el score final cambia y que con cinco jueces se descarta el
   valor mas alto y mas bajo.
5. Presionar `R` para reiniciar el round.
6. Presionar `N` para avanzar al siguiente atleta.
