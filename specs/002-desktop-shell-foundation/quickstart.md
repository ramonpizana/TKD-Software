# Quickstart: Desktop Shell Foundation

## 1. Instalar dependencias Node

```bash
npm install
```

## 2. Verificar el flujo web actual

```bash
npm run dev
```

Abre `http://127.0.0.1:5173/`.

## 3. Revisar prerequisitos de escritorio

```bash
npm run desktop:doctor
```

Si el comando falla, sigue
[docs/desktop/windows-setup.md](/C:/Users/ramon/Documents/TKD/docs/desktop/windows-setup.md).

## 4. Cuando Rust ya este instalado

```bash
npm run desktop:dev
```

## 5. Cuando quieras bundle de Windows

```bash
npm run desktop:build
```

## 6. Validacion general del repo

```bash
npm run validate
```
